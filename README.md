# 💻 Tecnologia para Todos

## Promover a Inclusão Digital

Projeto desenvolvido como parte da **Atividade Extensionista II** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O projeto tem como objetivo contribuir para a inclusão digital por meio de um site simples e acessível,
com conteúdos voltados para pessoas que possuem pouca experiência com tecnologia.

## 🎯 Objetivo

Disponibilizar informações básicas que possam ajudar a comunidade a utilizar recursos digitais no dia a dia com mais facilidade 
e segurança.

## 🌐 Site do projeto

👉 **Acesse o site:**
https://marcos-vr.github.io/tecnologia-Site/index.html

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap

## 📚 Conteúdos

O site apresenta conteúdos relacionados a:

* Uso do e-mail
* Serviços digitais
* Segurança na internet
* Proteção de dados e senhas
* Cuidados contra golpes
* Quiz sobre segurança digital
